## Project Overview
A marketplace connecting students who need help with peer tutors, with bookings and ratings.

## Implemented Must-Haves
- [x] Tutor profiles
- [x] session booking
- [x] ratings and reviews
- [x] booking history for both sides

## Key Learning Outcomes
- Model bookings and reviews
- build search and profile pages
- handle two-sided users.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (or React / Vite / Next.js)
- **AI & Logic:** Generative AI prompt engineering, external APIs, state management
- **Deployment:** Vercel / Netlify / GitHub Pages (Deploy anywhere with zero restrictions!)

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/hitikadhiman/Peer-Tutoring-Marketplace.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Peer-Tutoring-Marketplace
   ```
3. Open `index.html` directly in your browser, or run your local dev server:
   ```bash
   # If using npm / Vite:
   npm install
   npm run dev
   ```
